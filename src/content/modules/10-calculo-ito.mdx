## 1. Integrar contra una trayectoria sin tangente

La variación cuadrática del módulo pasado deja una consecuencia práctica
inmediata: $\int_0^t f(s)\, dW_s$ **no puede** definirse al estilo
Riemann-Stieltjes, porque $W$ no es de variación finita. La definición que
funciona es la de Itô: la integral como límite en media cuadrática de sumas
evaluadas en el **extremo izquierdo**:

$$\int_0^t f(s)\, dW_s = \lim \sum_k f(t_k)\,(W_{t_{k+1}} - W_{t_k})$$

Evaluar a la izquierda no es un detalle técnico: es lo que hace que el
integrando nunca vea el futuro. Con esa elección la integral hereda la
propiedad más valiosa del curso:

La evaluación a la izquierda tiene un precio: la integral ya no se comporta
como la regla de la cadena clásica. Esa diferencia es el lema de Itô.

## 2. El lema de Itô: la regla de la cadena corregida

Para una función $f$ dos veces derivable, el desarrollo de Taylor de
$f(W_{t+dt}) - f(W_t)$ tiene un término que en el cálculo clásico se
descartaría: como $(dW_t)^2 = dt$ (variación cuadrática, módulo 9), el
segundo orden no se evapora sino que aporta $dt$. Resultado:

$$df(W_t) = f'(W_t)\, dW_t + \tfrac{1}{2} f''(W_t)\, dt$$

La **corrección de Itô** $\frac{1}{2}f'' dt$ es el precio de la rugosidad.
Ejemplos que piden el Quiz 3 y el Taller 2:

- $f(x) = x^2$: $d(W_t^2) = 2W_t\, dW_t + dt$, es decir
  $W_t^2 = 2\int W_s\, dW_s + t$. Reordenando: $\int_0^t W_s\, dW_s =
  \frac{1}{2}(W_t^2 - t)$ — la integral explícita del Taller 2, con su
  corrección $-t$ frente al $\frac{1}{2}W_t^2$ clásico.
- $f(x) = x^3$: $d(W_t^3) = 3W_t^2\, dW_t + 3W_t\, dt$, y reordenando,
  $W_t^3 - 3tW_t = \int (3W_s^2 - 3s)\, dW_s$: la **martingala cúbica** que
  el Quiz 3 pide verificar.
- $f(x) = e^{\theta x}$: $d(e^{\theta W_t}) = \theta e^{\theta W_t} dW_t +
  \frac{\theta^2}{2} e^{\theta W_t} dt$, de donde $e^{\theta W_t -
  \theta^2 t/2}$ es martingala (la exponencial del módulo 9).

Para un proceso general $X_t$ con $dX_t = b_t\, dt + \sigma_t\, dW_t$, el
lema completo agrega el término de deriva:

$$df(X_t) = \left(f' b_t + \tfrac{1}{2} f'' \sigma_t^2\right) dt + f' \sigma_t\, dW_t$$

<RCell
  id="10/ito-lema"
  title="La corrección de Itô en números"
  code={`set.seed(41)
n <- 2000; grid <- seq(0, 1, length.out = n)
dW <- c(0, rnorm(n - 1)) / sqrt(n)
W <- cumsum(dW)

# Int W dW por sumas de Itô (extremo izquierdo)
ito <- sum(W[-n] * dW[-1])
cat("Int W dW (sumas):", sprintf("%.4f", ito), "\\n")
cat("(W(1)^2 - 1)/2  :", sprintf("%.4f", (tail(W,1)^2 - 1)/2), "\\n")
cat("W(1)^2 / 2 (clásico):", sprintf("%.4f", tail(W,1)^2/2),
    " <- difiere por la corrección -t/2\\n")

# La cúbica: W^3 - 3tW debe ser martingala -> media cero en todo t
reps <- 2000
M <- replicate(reps, {
  w <- c(0, cumsum(rnorm(999)) / sqrt(999))
  w[500]^3 - 3 * (500/999) * w[500]     # t = 0.5
})
cat("E[W(0.5)^3 - 3·0.5·W(0.5)]:", sprintf("%.4f", mean(M)),
    "| ee:", sprintf("%.4f", sd(M)/sqrt(reps)), "\\n")

# Integral gaussiana: Int_0^1 s dW(s) debe ser N(0, 1/3)
I_gauss <- sum(grid[-n] * dW[-1])
cat("Var teórica:", sprintf("%.4f", sum(grid[-n]^2)/n),
    "≈ 1/3 | valor simulado:", sprintf("%.4f", I_gauss), "\\n")`}
/>

## 3. Por qué la cúbica es martingala

La verificación del Quiz 3 pide mostrar que $M_t = W_t^3 - 3tW_t$ es
martingala. Con el lema: $dM = 3(W_t^2 - t)\, dW_t$ — el término $dt$ se
cancela exactamente porque se construyó para eso. Como $M$ es una integral
de Itô pura (sin deriva), es martingala. Es el mismo patrón de las
martingalas del módulo 9: cada corrección ($-t$, $-3tW$, $-\theta^2 t/2$)
existe para aniquilar el término de deriva que el lema produce.

<Callout type="tip" title="Itô vs Stratonovich">

Evaluar el integrando en el punto medio en vez del extremo da la integral de
**Stratonovich**, que obedece la regla de la cadena clásica pero pierde la
propiedad de martingala y de anticipación nula. En finanzas y en este curso
se usa Itô: el integrando no puede ver el futuro. La diferencia entre ambas
es otra vez el término de corrección de segundo orden.

</Callout>

n <- 2001; grid <- seq(0, 1, length.out = n)
dW <- c(0, rnorm(n - 1)) / sqrt(n)
W <- cumsum(dW)

# ---- 1 y 4. Izquierda (Itô) vs punto medio (Stratonovich) ----
ito <- sum(W[-n] * dW[-1])
strat <- sum((W[-n] + W[-1]) / 2 * dW[-1])
cat("Itô        :", sprintf("%.4f", ito), "vs (W1^2-1)/2 =",
    sprintf("%.4f", (tail(W,1)^2 - 1)/2), "\\n")
cat("Stratonovich:", sprintf("%.4f", strat), "vs W1^2/2 =",
    sprintf("%.4f", tail(W,1)^2 / 2), "\\n")

# ---- 2. Verificacion de martingalas en t = 0.5 ----
reps <- 3000
w5 <- replicate(reps, sum(rnorm(500)) / sqrt(999))
cat("E[W^2 - t] :", sprintf("%.4f", mean(w5^2 - 0.5)), "\\n")
cat("E[W^3 - 3tW]:", sprintf("%.4f", mean(w5^3 - 1.5 * w5)), "\\n")
# W^3 sola no es martingala: E[W_t^3 | W_s] != W_s^3 en general.
# Chequeo con el incremento: E[(W_s + dW)^3 | W_s] = W_s^3 + 3 W_s (dt)
cat("Sesgo de W^3 sola: E[W^3|W_s] - W_s^3 = 3·W_s·dt -> no martingala\\n")

# ---- 3. Integral gaussiana N(0, 1/3) ----
I <- replicate(reps, {
  dw <- rnorm(1000) / sqrt(1000)
  g <- (0:999) / 1000
  sum(g * dw)
})
cat("Var empirica:", sprintf("%.4f", var(I)),
    "| isometria:", sprintf("%.4f", 1/3), "\\n")
qqnorm(I, col = "#8b5cf6", pch = ".",
       main = "Integral s dW ~ N(0, 1/3)")
qqline(I, col = "#5b21b6", lwd = 2)`}
