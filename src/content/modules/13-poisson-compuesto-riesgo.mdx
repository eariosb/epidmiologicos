## 1. Cada evento trae una magnitud

El Poisson del módulo 6 contaba eventos idénticos: cada reclamación sumaba
uno. En la realidad las reclamaciones tienen **severidad**: cada evento $k$
llega en el instante $T_k$ con un monto aleatorio $Y_k$. El **proceso de
Poisson compuesto** es

$$S(t) = \sum_{k=1}^{N(t)} Y_k$$

con $N$ Poisson($\lambda$) y las $Y_k$ i.i.d. independientes de $N$. La
contabilidad básica que usa el Taller 2:

$$E[S(t)] = \lambda t\, E[Y], \qquad \mathrm{Var}(S(t)) = \lambda t\, E[Y^2]$$

La varianza usa el segundo momento, no el cuadrado de la media: el azar del
conteo y el de las magnitudes se suman. La función generadora de momentos
cierra la descripción: $M_{S(t)}(r) = \exp(\lambda t\,(M_Y(r) - 1))$.

## 2. El surplus del asegurador

El modelo de **Cramér-Lundberg** pone la contabilidad en movimiento: la
aseguradora empieza con capital $u$, cobra primas a tasa constante $c$ por
unidad de tiempo y paga el Poisson compuesto $S(t)$:

$$U(t) = u + ct - S(t)$$

El proceso es una carrera entre dos tendencias: la prima acumula
linealmente, las reclamaciones restan en saltos de tamaños aleatorios. La
condición de viabilidad es la **carga de seguridad positiva**: el ingreso
esperado debe superar la pérdida esperada,

$$c > \lambda\, E[Y]$$

y la diferencia relativa $\rho = c/(\lambda E[Y]) - 1$ es la carga de
seguridad. Con $\rho \leq 0$ la ruina es casi segura: no hay prima que
resista un flujo esperado negativo.

## 3. La probabilidad de ruina y el coeficiente de Lundberg

La **ruina** es el evento $U(t) < 0$ para algún $t$: el primer paso del
surplus por debajo de cero — otra vez un problema de primera llegada, ahora
con saltos. Con severidades exponenciales de media $1/\beta$ hay forma
cerrada, pero el resultado general que importa es la **cota de Lundberg**:
si existe $R > 0$ solución de

$$\lambda\,(M_Y(R) - 1) = cR$$

entonces $\psi(u) \leq e^{-Ru}$. Esa $R$ es el **coeficiente de ajuste**: la
tasa exponencial a la que la probabilidad de ruina decae con el capital
inicial. Con $Y$ exponencial de media $1/\beta$ se despeja en forma cerrada:
$R = \beta - \lambda/c$, y de hecho $\psi(u) = \frac{\lambda}{c\beta}
e^{-Ru}$ en ese caso.

<Callout type="tip" title="Lundberg como martingala">

La cota no es casualidad: el proceso $e^{-RU(t)}$ es martingala
precisamente porque $R$ satisface $\lambda(M_Y(R) - 1) = cR$. La parada
opcional del módulo 8 sobre el tiempo de ruina produce la desigualdad. Las
piezas del curso se van conectando solas.

</Callout>

## 4. Simulación de la ruina

Cuando las severidades no son exponenciales — lognormales en el Trabajo 2 —
no hay forma cerrada y la probabilidad de ruina se estima por Monte Carlo:
simular trayectorias del surplus y contar cuántas tocan cero. Como la ruina
es un evento raro con capital alto, la estimación cruda necesita muchas
réplicas; es la excusa perfecta para introducir el **error Monte Carlo**
explícito que el Trabajo 2 exige reportar con intervalos.

<RCell
  id="13/ruina-montecarlo"
  title="Ruina por Monte Carlo vs la fórmula exponencial"
  code={`set.seed(17)
lam <- 1; beta <- 1; c <- 1.5   # reclamaciones Exp(1), prima 1.5 > lambda*E[Y] = 1
u <- 20; horizonte <- 500; reps <- 2000

ruina <- function(u) {
  t <- 0; cap <- u
  repeat {
    dt <- rexp(1, lam)              # tiempo a la proxima reclamacion
    if (t + dt > horizonte) return(0)
    t <- t + dt
    cap <- cap + c * dt - rexp(1, beta)  # prima acumulada - severidad
    if (cap < 0) return(1)
  }
}
psi_sim <- mean(replicate(reps, ruina(u)))
R <- beta - lam / c
psi_teo <- (lam / (c * beta)) * exp(-R * u)
ee <- sqrt(psi_sim * (1 - psi_sim) / reps)
cat("Ruina MC:", sprintf("%.4f", psi_sim), "(ee", sprintf("%.4f", ee), ")",
    "| teorica:", sprintf("%.4f", psi_teo), "\\n")`}
/>

lam <- 1; c <- 1.5; horizonte <- 400; reps <- 3000

ruina <- function(u, severidad) {
  t <- 0; cap <- u
  repeat {
    dt <- rexp(1, lam)
    if (t + dt > horizonte) return(0)
    t <- t + dt
    cap <- cap + c * dt - severidad()
    if (cap < 0) return(1)
  }
}
exp_sev <- function() rexp(1, 1)
sig2 <- log(5); mu_ln <- -sig2/2     # lognormal media 1, var 4
ln_sev <- function() rlnorm(1, mu_ln, sqrt(sig2))
cat("media sev lognormal:", sprintf("%.2f", mean(replicate(20000, ln_sev()))), "\\n")

ic <- function(p, n) sprintf("%.4f ± %.4f", p, 1.96*sqrt(p*(1-p)/n))

# ---- 1 y 2. Ruina exponencial vs lognormal ----
for (u in c(5, 10, 20)) {
  p_exp <- mean(replicate(reps, ruina(u, exp_sev)))
  p_ln  <- mean(replicate(reps, ruina(u, ln_sev)))
  teo <- (lam/(c*1)) * exp(-(1 - lam/c) * u)
  cat("u =", u, "| exp:", ic(p_exp, reps), "(teo", sprintf("%.4f", teo), ")",
      "| lnorm:", ic(p_ln, reps), "\\n")
}

# ---- 3. Capital minimo para psi < 0.05 ----
u <- 5
while (mean(replicate(1500, ruina(u, ln_sev))) > 0.05 && u < 120) u <- u + 5
cat("u* lognormal para psi < 0.05:", u,
    "| u* formula exp:", sprintf("%.0f", -log(0.05 * c / lam) / (1 - lam/c)), "\\n")`}
