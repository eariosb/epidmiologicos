## 1. Una sola variable no alcanza

Hasta ahora, el curso de probabilidad le preguntaba a un dado quieto: modelar
$X$, una variable aleatoria con su distribución, esperanza y varianza. El mundo
real, en cambio, rara vez se queda quieto. El número de siniestros que llega a
una aseguradora cambia semana a semana, el precio de un bono oscila cada
segundo, el nivel de un embalse sube y baja con las lluvias, una epidemia
crece y decae, una población se ramifica generación tras generación.

En todos estos fenómenos el azar no aparece una vez: **evoluciona**. Necesitamos
un objeto matemático que capture esa evolución, y ese objeto es el proceso
estocástico.

<Callout type="note" title="La idea central del curso">

Un proceso estocástico no es una distribución: es una **familia de
distribuciones** organizada por el tiempo. Conocer el proceso significa saber
cómo se relacionan entre sí las observaciones de ayer, hoy y mañana, no solo
cómo se distribuye cada una por separado.

</Callout>

## 2. Definición y vocabulario esencial

Un proceso estocástico es una familia
$\{X_t : t \in T\}$ de variables aleatorias, todas definidas sobre el mismo
espacio de probabilidad $(\Omega, \mathcal{F}, P)$, con valores en un conjunto
$E$ llamado **espacio de estados**. El índice $t$ vive en un conjunto $T$,
usualmente el tiempo.

Dos atributos clasifican de inmediato cualquier proceso:

- **El índice $T$**: si es discreto ($T = \{0, 1, 2, \dots\}$) el proceso es de
  **tiempo discreto**; si es un intervalo ($T = [0, \infty)$) es de **tiempo
  continuo**.
- **El espacio de estados $E$**: si $E$ es numerable el proceso es **discreto**
  (o de salto); si $E = \mathbb{R}$ o $\mathbb{R}^d$ es **continuo**.

Con esa rejilla, los ejemplos canónicos del curso se ordenan solos:

| Proceso | $T$ | $E$ |
|---|---|---|
| Caminata aleatoria | discreto | discreto |
| Cadena de Markov | discreto | discreto |
| Proceso de ramificación (Galton-Watson) | discreto | $\{0,1,2,\dots\}$ |
| Proceso de Poisson (conteo de eventos) | continuo | $\{0,1,2,\dots\}$ |
| Movimiento browniano | continuo | $\mathbb{R}$ |
| Ecuaciones diferenciales estocásticas | continuo | $\mathbb{R}$ |

<Callout type="tip" title="Trayectoria contra ley del proceso">

Fijar $t$ y variar $\omega$ da una variable aleatoria $X_t$. Fijar
$\omega$ y variar $t$ da una **trayectoria**: una función del tiempo, una
película de la realización. Cuando simulamos en R, dibujamos trayectorias;
cuando calculamos, trabajamos con la **ley del proceso** (las
distribuciones finito-dimensionales de $(X_{t_1}, \dots, X_{t_k})$ y cómo se
correlacionan). Confundir las dos vistas es el error conceptual más común del
curso.

</Callout>

## 3. El primer simulador: la caminata aleatoria

Ningún proceso es más productivo para empezar. Un apostador juega $n$ rondas;
en cada ronda gana o pierde una unidad con probabilidad $p$. Su capital
acumulado después de $t$ rondas es:

$$S_t = X_1 + X_2 + \cdots + X_t, \qquad X_i = \begin{cases} +1 & \text{con prob. } p \\ -1 & \text{con prob. } 1-p \end{cases}$$

Eso es todo: la caminata aleatoria es la suma de pasos iid. Y sin embargo,
de ahí saldrán en este curso el movimiento browniano (módulo 9, como límite
con escalado), la ruina del apostador y hasta precios de acciones.

<RCell
  id="01/caminata-3-trayectorias"
  title="Tres películas del mismo azar"
  code={`set.seed(10)
n <- 400
# Tres trayectorias de la caminata aleatoria simetrica
plot(0:n, c(0, cumsum(sample(c(-1, 1), n, TRUE))),
     type = "l", ylim = c(-40, 40), col = "#5b21b6",
     xlab = "ronda t", ylab = expression(S[t]),
     main = "Caminata aleatoria simétrica: 3 trayectorias")
for (i in 1:2) lines(0:n, c(0, cumsum(sample(c(-1, 1), n, TRUE))),
                     col = "#a78bfa")
abline(h = 0, col = "grey60", lty = 2)`}
/>

Ejecuta la celda varias veces (Ctrl+Shift+S captura la gráfica si quieres
llevarla a la pizarra). Tres preguntas valen más que mil definiciones:

1. ¿Las tres trayectorias se parecen entre sí? ¿Alguna "ley" puedes leer aún?
2. ¿Hacia dónde parece ir el nivel típico cuando $p = 0.5$? ¿Y si cambias
   `sample` para tener probabilidad 0.6 de subir?
3. ¿Qué le pasa a la **dispersión vertical** de las trayectorias conforme $t$
   crece?

La última pregunta tiene respuesta exacta: como $S_t$ es suma de variables
iid, $E[S_t] = (2p-1)\,t$ y $\mathrm{Var}(S_t) = 4p(1-p)\,t$. La dispersión
crece como $\sqrt{t}$: el azar se acumula, no se promedia.

<RCell
  id="01/caminata-teoria-vs-simulacion"
  title="La teoría contra la simulación"
  code={`set.seed(42)
n <- 500; m <- 2000
# m trayectorias hasta el tiempo n: en cada corrida, S_n
 finales <- replicate(m, sum(sample(c(-1, 1), n, TRUE)))

# Teoria de S_n en la caminata simetrica: media 0, varianza n
cat("Media simulada :", mean(finales), " teorica: 0\n")
cat("Desviacion est.:", sd(finales), " teorica:", sqrt(n), "\n")

# Histograma de S_n contra la normal aproximada ( TCL en accion )
hist(finales, breaks = 40, freq = FALSE, main = "S_n en t = 500: simulado vs aproximado",
     col = "#ede9fe", border = "#5b21b6", xlab = "S_500")
curve(dnorm(x, 0, sqrt(n)), add = TRUE, col = "#312e81", lwd = 2)`}
/>

El histograma de $S_{500}$ ya tiene forma de campana. No es casualidad: con
$t$ grande, la caminata simétrica se comporta como una normal
$N(0, t)$ por el teorema central del límite, y esa es exactamente la puerta
de entrada al movimiento browniano del bloque III.

## 4. El proceso de Galton-Watson: ramificación y extinción

El texto guía abre con este proceso porque muestra, en estado puro, el
fenómeno que perseguirá todo el curso: un mecanismo aleatorio **iterado**
cuya dinámica puede crecer sin freno o extinguirse, sin término medio.

La receta: cada individuo de la generación $t$ tiene un número aleatorio de
hijos $X$, con distribución fija en $\{0, 1, 2, \dots\}$. La generación
$t+1$ es la suma de los hijos de todos los individuos vivos. Si en algún
momento $Z_t = 0$, el proceso se extingue para siempre.

$$Z_{t+1} = \sum_{i=1}^{Z_t} X_i^{(t)}, \qquad Z_0 = 1$$

<ProcessSteps
  title="El mecanismo de ramificación, paso a paso"
  steps={[
    {
      title: "Generación 0",
      description: "Se parte de un único fundador: Z_0 = 1."
    },
    {
      title: "Reproducción",
      description: "Cada individuo vivo sortea su número de hijos con una distribución fija (p. ej. Poisson con media m)."
    },
    {
      title: "Siguiente generación",
      description: "Z_{t+1} es la suma de todos los hijos de la generación t. Los padres mueren: solo viven los hijos."
    },
    {
      title: "Absorción en cero",
      description: "Si Z_t llega a 0, no hay nadie que pueda reproducirse: 0 es un estado absorbente y la extinción es definitiva."
    }
  ]}
/>

La esperanza tiene una recurrencia lineal que se resuelve de una pasada:
$E[Z_{t+1}] = m\,E[Z_t]$, de donde $E[Z_t] = m^t$. Todo el destino del
proceso está en la **media reproductiva** $m$: crece si $m > 1$, se apaga si
$m < 1$, y con $m = 1$ deambula como una caminata crítica.

<Callout type="warning" title="La sorpresa del caso crítico">

Con $m = 1$ la esperanza se queda constante en 1 para siempre, y sin embargo
el proceso se extingue con probabilidad **uno**. La esperanza de la población
no es la probabilidad de sobrevivir: el proceso pasa cada vez más tiempo en
cero mientras una fracción minúscula de trayectorias gigantes sostiene la
media. Es la primera lección fuerte del curso sobre por qué $E[X_t]$ puede
ser un resumen engañoso de la dinámica.

</Callout>

<RCell
  id="01/galton-watson-supervivencia"
  title="Galton-Watson: crecer, deambular o extinguirse"
  code={`set.seed(2026)
generaciones <- 60

galton_watson <- function(m, G = generaciones, n0 = 1) {
  z <- numeric(G + 1); z[1] <- n0
  for (t in 1:G) {
    if (z[t] == 0) break
    z[t + 1] <- sum(rpois(z[t], m))   # cada padre: Poisson(m) hijos
  }
  z
}

par(mfrow = c(1, 3))
for (m in c(0.8, 1.0, 1.3)) {
  plot(0:generaciones, galton_watson(m), type = "l", lwd = 2,
       col = "#5b21b6", xlab = "generación t", ylab = "Z_t",
       main = paste0("m = ", m))
}
par(mfrow = c(1, 1))

# Extincion en el caso critico: 500 fundadores independientes
set.seed(7)
m <- 1.0
fundadores <- 500
extintas <- replicate(fundadores, {
  z <- 1
  for (t in 1:generaciones) {
    if (z == 0) break
    z <- sum(rpois(z, m))
  }
  z == 0
})
cat("Poblaciones extintas en t =", generaciones, ":",
    mean(extintas) * 100, "%\n")`}
/>

Con $m = 1$ la fracción extinta converge a 100% conforme pasan las
generaciones: la extinción es cierta, aunque $E[Z_t] = 1$ siempre. Con
$m = 1.3$ el proceso suele explotar hacia arriba; con $m = 0.8$ se apaga
rápido.

toca_nivel <- function(p, n, nivel) {
