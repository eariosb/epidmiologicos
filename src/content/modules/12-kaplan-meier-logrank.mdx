<Callout type="tip" title="La censura se maneja multiplicando">
<Term k="KM">Kaplan–Meier</Term> responde a la pregunta "¿qué fracción
sobrevive más allá de t?" multiplicando las probabilidades condicionales
de pasar cada tiempo de evento. Las censuras dejan de contar después de
su último día, sin borrarse de la historia.

## La construcción

$$
\hat S(t) = \prod_{t_i \le t}\left(1 - \frac{d_i}{n_i}\right)
$$

donde $d_i$ son los eventos en $t_i$ y $n_i$ los que siguen **en riesgo**
justo antes. La curva es un escalón que solo cae en tiempos de evento;
las censuras son marcas, no caídas. La animación siguiente construye la
curva paso a paso sobre ese principio.

El código que sigue implementa el producto acumulado a mano sobre los
datos de Freireich y luego verifica el resultado con `survival::survfit`,
que además produce las curvas por brazo y las medianas con su <Term k="IC">IC</Term>.

<RCell
  id="12/km-leucemia"
  title="Kaplan–Meier a mano y con survival"
  code={`# Datos de clase (leucemia.txt): grupo, tiempo, status.
leu <- read.table("leucemia.txt", header = TRUE)
print(head(leu, 4)); cat("...\\n"); print(table(leu$grupo, leu$status))

# Kaplan-Meier a mano: producto acumulado de (1 - d/n) por tiempo.
km_mano <- function(t, s) {
  te <- sort(unique(t[s == 1]))
  S <- 1; out <- data.frame(t = 0, S = 1)
  for (ti in te) {
    n <- sum(t >= ti); d <- sum(t == ti & s == 1)
    S <- S * (1 - d/n)
    out <- rbind(out, data.frame(t = ti, S = S))
  }
  out
}
km0 <- km_mano(leu$tiempo[leu$grupo==0], leu$status[leu$grupo==0])
km1 <- km_mano(leu$tiempo[leu$grupo==1], leu$status[leu$grupo==1])
print(km0); print(km1)

# Verificacion con el paquete survival (clasico de webR):
library(survival)
sf <- survfit(Surv(tiempo, status) ~ grupo, data = leu)
print(summary(sf))
plot(sf, col = c("#dc2626", "#0284c7"), lwd = 2,
     xlab = "semanas", ylab = "S(t)", mark.time = TRUE)
legend("bottomleft", c("placebo", "6-MP"), col = c("#dc2626","#0284c7"),
       lwd = 2, bty = "n")`}
/>

<SasBlock code={`proc import datafile="leucemia.txt" out=leu dbms=dlm replace;
  delimiter=' '; getnames=yes;
run;
/* PROC LIFETEST = KM + log-rank + medianas con IC, todo en uno:
   TIME tiempo*status(0)  -> status=0 es la censura
   STRATA grupo           -> curva por brazo y test log-rank */
proc lifetest data=leu method=km plots=survival;
  time tiempo*status(0);
  strata grupo;
run;
/* La salida 'Quartile Estimates' da la mediana (8 sem. placebo;
   NR en 6-MP) y 'Test of Equality' el log-rank */`} />

## Los tipos de censura

La censura a derecha es la común, pero no la única:

- **Derecha**: el evento ocurre *después* del último contacto — pérdidas,
  cierre del estudio, retiro. Es la que KM absorbe de forma nativa.
- **Izquierda**: el evento ya ocurrió *antes* de la primera observación —
  un paciente que entra al estudio con infección de fecha desconocida.
  Solo se sabe que ocurrió antes de t.
- **Por intervalo**: el evento ocurrió entre dos visitas, en fecha
  desconocida — serología que cambia entre controles anuales. Requiere
  métodos especiales (estimador de Turnbull), no KM estándar.

Y el eje ortogonal, más decisivo: **informativa vs. no informativa**.
KM y log-rank asumen que censurar no cambia el riesgo residual del
paciente: censura *informativa* (el paciente que se retira porque
empeora) rompe el supuesto y ninguna técnica de las vistas lo repara —
mismo principio que el sesgo por pérdidas del módulo 11, ahora con
nombre estadístico.

## El test de log-rank

El <Term k="log-rank">log-rank</Term> acumula en cada tiempo de evento la
diferencia **observado − esperado** por grupo, como un χ² que respeta el
tiempo:

$$
\chi^2_{LR} = \frac{\left(\sum_i (O_{1i} - E_{1i})\right)^2}
{\sum_i V_{1i}}
$$

La comparación corre con `survdiff` (el log-rank de R) y el resumen de
`survfit` entrega la mediana por brazo con su IC95%. Sobre estos datos
aparece una lectura importante: la mediana del grupo tratado no se
alcanza porque S(t) nunca baja de 0.5.

<RCell
  id="12/logrank"
  title="Log-rank en la leucemia y el IC de la mediana"
  code={`library(survival)
leu <- read.table("leucemia.txt", header = TRUE)

# El test log-rank: O-E acumulado entre grupos.
print(survdiff(Surv(tiempo, status) ~ grupo, data = leu))

# Mediana de supervivencia por grupo con su IC95%:
sf <- survfit(Surv(tiempo, status) ~ grupo, data = leu)
print(sf)

# Lectura de clase (Salazar): en 6-MP la mediana no se alcanza
# (S nunca baja de 0.5); en placebo son 8 semanas.`}
/>

<SasBlock code={`/* survdiff -> el log-rank de STRATA en PROC LIFETEST;
   survfit -> la tabla Product-Limit y los cuartiles */
proc lifetest data=leu method=km;
  time tiempo*status(0);
  strata grupo / test=logrank;
run;`} />

<Callout type="warning" title="El log-rank compara curvas, no puntos">
Un log-rank significativo dice que las curvas difieren **en conjunto**,
no en un tiempo concreto; y al revés, un log-rank no significativo puede
convivir con una ventaja temprana grande que se desvanece al final (las
curvas que se cruzan son su punto ciego: anticipan la violación del
supuesto de riesgos proporcionales del módulo 13). Si la pregunta
clínica es puntual —"¿a 23 semanas quién va mejor?"— la respuesta es
S(t) por brazo con su IC, como hace el laboratorio de decisión de
abajo, no el p del log-rank.
</Callout>

<Callout type="note" title="Log-rank y sus primos sin censura">
Con dos grupos y sin censura, el log-rank equivale al test de Savage
(scores exponenciales) aplicado a los tiempos; el test que sí se reduce a
Wilcoxon es su variante ponderada Gehan–Breslow (pesos = tamaños del
riesgo). La censura es lo que hace necesaria la familia: sin ella se
recuperan los tests de siempre (clase 15). Y un puente hacia el bloque II: la
mortalidad del SHHS se analizó también con <Term k="CMH">CMH</Term> sobre
una tabla 2×2×9 estratificada (clase 16, <code>mantelhaen.test</code>),
mostrando que la estratificación clásica y la supervivencia comparten
la misma lógica observado-menos-esperado.
</Callout>

## Laboratorio de decisión · ¿adoptar 6-MP como terapia de mantenimiento?

<Callout type="note" title="Caso: Freireich 1963, el ensayo que fundó la quimioterapia moderna">
42 niños con leucemia en remisión se aleatorizaron a 6-MP o placebo; el
desenlace es la recaída. El ensayo es pequeño y tiene censuras, pero la
enfermedad sin tratamiento es casi siempre fatal. ¿Se adopta el 6-MP como
mantenimiento estándar con esta evidencia?
</Callout>

El análisis toma S(23) por brazo, lo convierte en riesgo de recaída y de
ahí en ARR y <Term k="NNT">NNT</Term> a horizonte fijo; el log-rank completa la comparación
sobre las curvas completas.

<RCell
  id="12/decision-6mp"
  title="De S(t) al NNT"
  code={`library(survival)
leu <- read.table("leucemia.txt", header = TRUE)

sf <- survfit(Surv(tiempo, status) ~ grupo, data = leu)
s  <- summary(sf, times = 23)     # S(23) por brazo; estrato 1 = placebo
print(s)                        # trae el IC Greenwood de cada S(23)
r_ctrl <- 1 - s$surv[1]         # 1.00: los 21 del placebo recayeron
r_trat <- 1 - s$surv[2]         # 0.55
arr  <- r_ctrl - r_trat         # = S_6MP(23) - S_placebo(23) = 0.45

# IC del ARR estilo Newcombe: combina el IC Greenwood de S_6MP(23)
# [lower, upper del summary] con un IC de Wilson para S_placebo (0/21).
wilson <- function(x, n, z = 1.96) {
  ce <- (x + z^2/2)/(n + z^2); hw <- z/(n + z^2)*sqrt(x*(n-x)/n + z^2/4)
  c(max(0, ce - hw), min(1, ce + hw))
}
ic_sp <- wilson(0, 21)                       # S_placebo: [0, 0.15]
ic_st <- c(s$lower[2], s$upper[2])           # S_6MP Greenwood
cat(sprintf("riesgo recaida 23sem: placebo = %.2f  6-MP = %.2f\\n",
            r_ctrl, r_trat))
cat(sprintf("ARR = %.2f [%.2f, %.2f]  ->  NNT(23 sem) = %.1f\\n",
            arr, ic_st[1] - ic_sp[2], ic_st[2] - ic_sp[1], 1/arr))
# Esperado: ARR = 0.45 [~0.09, ~0.81] -> NNT ~ 2.2. El IC es ancho:
# la decision es robusta pero la magnitud exacta no.
print(survdiff(Surv(tiempo, status) ~ grupo, data = leu))
cat("\\nEl NNT horizonte-fijo usa S(t): es el puente KM -> decision.\\n")`}
/>

/* S(23) por brazo y ARR/NNT se leen de survdat */`} />
