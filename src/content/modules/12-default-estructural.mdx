## 1. El default como evento de primer paso

La idea de Merton (1974) traduce el crédito a geometría del browniano: el
valor de los activos de la firma $V_t$ sigue un browniano geométrico, la
deuda es un cero-cupón de nominal $D$ que vence en $T$, y el **default
ocurre si al vencimiento los activos no alcanzan a cubrir la deuda**:
$V_T < D$. En ese caso los tenedores de deuda reciben lo que hay, $V_T$, y
la pérdida es $D - V_T$.

Es un modelo de **primer paso en horizonte fijo**: solo importa dónde
termina el proceso, no el camino. Black-Cox lo endurece: el default ocurre
**en cuanto** $V_t$ toca una barrera $H < D$, en cualquier momento antes o
en el vencimiento — un problema de primera llegada de un browniano con
deriva a un nivel, que es exactamente lo que el principio de reflexión del
módulo 9 resuelve.

## 2. Merton: default solo al vencimiento

Con $V_t = V_0 e^{(\mu - \sigma^2/2)t + \sigma W_t}$, el default en $T$
equivale a un evento gaussiano sobre $W_T$:

$$P(V_T < D) = P\left(W_T < \frac{\log(D/V_0) - (\mu - \sigma^2/2)T}{\sigma}\right) = \Phi(d_-)$$

donde $d_-$ es la distancia estandarizada del log-activo a la barrera. Es
la misma cuenta que la opción put de Black-Scholes — la deuda riesgosa es
un bono libre de riesgo menos un put sobre los activos, y esa simetría es
la lección profunda del modelo.

La **pérdida esperada** exige un paso más: $E[(D - V_T)^+]$, la esperanza
de un put. En forma cerrada,

$$E[\text{pérdida}] = D\,\Phi(d_-) - V_0 e^{\mu T}\,\Phi(d_- - \sigma\sqrt{T})$$

<RCell
  id="12/merton-blackcox"
  title="Probabilidades de default: Merton vs Black-Cox"
  code={`set.seed(84)
V0 <- 120; D <- 100; H <- 70          # activos, deuda, barrera Black-Cox
mu <- 0.05; sigma <- 0.25; T <- 3

# ---- Merton: default solo al vencimiento ----
d_menos <- (log(D/V0) - (mu - sigma^2/2)*T) / (sigma * sqrt(T))
pd_merton <- pnorm(d_menos)
cat("PD Merton:", sprintf("%.4f", pd_merton), "\\n")

# Monte Carlo de control
VT <- V0 * exp((mu - sigma^2/2)*T + sigma*sqrt(T)*rnorm(20000))
cat("PD Merton sim:", sprintf("%.4f", mean(VT < D)), "\\n")

# ---- Black-Cox: default al tocar H antes de T ----
# Browniano con deriva: log V_t toca log(H/V0)/sigma como proceso con
# deriva (mu - sigma^2/2)/sigma. PD por primera llegada.
a <- -log(V0/H) / sigma              # barrera en unidades brownianas (a<0)
b <- (mu - sigma^2/2) / sigma        # deriva browniana
pd_bc <- pnorm((a - b*T)/sqrt(T)) +
         exp(2*a*b) * pnorm((a + b*T)/sqrt(T))
cat("PD Black-Cox:", sprintf("%.4f", pd_bc), "\\n")

# Simulacion de primera llegada
pasos <- 800
dt <- T / pasos
default_bc <- function() {
  w <- 0
  for (i in 1:pasos) {
    w <- w + b*dt + rnorm(1)*sqrt(dt)
    if (w <= a) return(TRUE)
  }
  FALSE
}
cat("PD Black-Cox sim:", sprintf("%.4f", mean(replicate(5000, default_bc()))), "\\n")`}

## 3. Black-Cox: la barrera que vigila siempre

La probabilidad de default de Black-Cox usa la ley de la **primera llegada
de un browniano con deriva** a un nivel: si $X_t = bt + W_t$ con $b$
arbitrario y $a < 0$ la barrera, entonces

$$P(\tau_a \leq T) = \Phi\!\left(\frac{a - bT}{\sqrt{T}}\right) + e^{2ab}\,\Phi\!\left(\frac{a + bT}{\sqrt{T}}\right)$$

El segundo término es la contribución del principio de reflexión corregido
por la deriva (un cambio de medida discreto). Dos lecturas que pide el Quiz
3:

- **Black-Cox domina a Merton**: el default puede ocurrir antes del
  vencimiento aunque al final el activo se recupere, así que $PD_{BC} \geq
  PD_{Merton}$ siempre. La vigilancia continua estrictamente más riesgosa
  para el deudor… y más segura para el acreedor, que se protege antes de
  que el activo se deteriore más.
- **La pérdida esperada no necesariamente sigue el mismo orden**: en
  Black-Cox el acreedor recibe $H$ (la barrera) en el instante del default,
  lo que puede superar al $V_T$ residual de Merton en escenarios malos. El
  laboratorio lo cuantifica.

<Callout type="tip" title="Estructural vs reducido">

Merton y Black-Cox son **estructurales**: el default emerge de la
contabilidad de la firma (activos vs deuda). El enfoque rival, reducido,
modela el default como el primer salto de un proceso de Poisson con
intensidad riesgosa — sin preguntar por qué. Los dos marcos conviven en el
mercado de CDS, y el Trabajo 3 compara sus predicciones sobre una empresa
colombiana real.

</Callout>

## 4. Lo que el modelo deja por fuera

Los modelos estructurales son pedagógicamente perfectos y prácticamente
incompletos: asumen activos observables (en la práctica $V_t$ se infiere
del precio de la acción vía Black-Scholes), deuda única y sin cupones, y
volatilidad constante. Las extensiones — KMV de Moody's, barreras
estocásticas, múltiples tramos de deuda — son el campo de juego del riesgo
de crédito moderno, y la parte empírica del Trabajo 3 discute exactamente
esas limitaciones con datos reales.

  code={`set.seed(91)
V0 <- 120; D <- 100; H <- 70
mu <- 0.05; sigma <- 0.25; T <- 3

# ---- 1. Probabilidades de default ----
d_menos <- (log(D/V0) - (mu - sigma^2/2)*T) / (sigma*sqrt(T))
pd_m <- pnorm(d_menos)
a <- -log(V0/H)/sigma; b <- (mu - sigma^2/2)/sigma
pd_bc <- pnorm((a - b*T)/sqrt(T)) + exp(2*a*b)*pnorm((a + b*T)/sqrt(T))
cat("PD Merton:", sprintf("%.4f", pd_m),
    "| PD Black-Cox:", sprintf("%.4f", pd_bc), "\\n")

# ---- 2. Perdida esperada Merton ----
el_m <- D*pnorm(d_menos) - V0*exp(mu*T)*pnorm(d_menos - sigma*sqrt(T))
VT <- V0*exp((mu - sigma^2/2)*T + sigma*sqrt(T)*rnorm(20000))
el_m_sim <- mean(pmax(D - VT, 0))
cat("EL Merton:", sprintf("%.4f", el_m),
    "| sim:", sprintf("%.4f", el_m_sim), "\\n")

# ---- 3. Perdida esperada Black-Cox (recovery = H al tocar) ----
pasos <- 400; dt <- T/pasos
perdida_bc <- function() {
  w <- 0                                  # browniano log-escalado
  for (i in 1:pasos) {
    w <- w + b*dt + rnorm(1)*sqrt(dt)
    if (w <= a) return(D - H)             # default: recovery = barrera
  }
  vT <- V0 * exp(w * sigma)               # V_T = V0 exp(sigma * w_T)
  max(D - vT, 0)
}
el_bc_sim <- mean(replicate(5000, perdida_bc()))
cat("EL Black-Cox sim:", sprintf("%.4f", el_bc_sim), "\\n")
cat("PD mayor pero severidad menor: BC protege en la barrera\\n")

# ---- 4. Sensibilidad a la volatilidad ----
sigmas <- seq(0.15, 0.45, by = 0.05)
pds <- sapply(sigmas, function(s) {
  d <- (log(D/V0) - (mu - s^2/2)*T) / (s*sqrt(T))
  pnorm(d)
})
plot(sigmas, pds, type = "b", col = "#5b21b6", pch = 16,
     main = "PD de Merton vs volatilidad de activos",
     xlab = "sigma", ylab = "PD a 3 años")`}
