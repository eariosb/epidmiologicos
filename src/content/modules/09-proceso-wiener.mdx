## 1. La caminata aleatoria, vista de lejos

En el módulo 1 simulamos la caminata aleatoria simple $S_n$: pasos $\pm 1$
independientes. Ahora imagina la misma caminata comprimida: en cada unidad de
tiempo caben $n$ pasos, cada uno de tamaño $1/\sqrt{n}$. Al crecer $n$, la
trayectoria se vuelve una curva continua, irregular, que nunca se suaviza del
todo. Ese límite — el teorema de Donsker lo formaliza — es el **proceso de
Wiener** o movimiento browniano $W = \{W_t\}_{t \geq 0}$.

La definición por propiedades es análoga a la del Poisson:

1. $W_0 = 0$.
2. **Incrementos independientes** en intervalos disjuntos.
3. **Incrementos gaussianos estacionarios**: $W_{t+s} - W_s \sim
   \mathrm{N}(0, t)$.
4. **Trayectorias continuas** con probabilidad 1.

Cambiar la ley de los incrementos de Poisson a normal cambia el tipo de
trayectoria: de escalera con saltos a curva continua sin puntos angulosos
"visibles" pero con rugosidad en toda escala.

## 2. Distribuciones y covarianza

Del axioma 3 sale toda la familia de distribuciones finito-dimensionales:
$W_t \sim \mathrm{N}(0, t)$, y para $s < t$, como $W_s$ es independiente del
incremento $W_t - W_s$:

$$\mathrm{Cov}(W_s, W_t) = \mathrm{Var}(W_s) = \min(s, t)$$

La misma forma $\lambda \min(s, t)$ del proceso de Poisson — los incrementos
independientes la producen en ambos. El proceso de Wiener es además
**gaussiano**: toda colección finita $(W_{t_1}, \dots, W_{t_k})$ es normal
multivariada, quedando la ley completa determinada por media cero y esa
covarianza.

Tres martingalas canónicas salen de la definición, y el Quiz 3 las usa:

- $W_t$ es martingala (incrementos centrados).
- $W_t^2 - t$ es martingala (la corrección cuadrática).
- $\exp(\theta W_t - \theta^2 t / 2)$ es martingala para todo $\theta$ (la
  exponencial, base del cambio de medida en finanzas).

<RCell
  id="09/wiener-trayectorias"
  title="Trayectorias brownianas por el límite de caminatas"
  code={`set.seed(14)
n <- 2000
grid <- seq(0, 1, length.out = n)

caminata <- function() {
  pasos <- sample(c(-1, 1), n - 1, TRUE)
  c(0, cumsum(pasos)) / sqrt(n)   # escala 1/sqrt(n): el truco de Donsker
}
W <- replicate(5, caminata())
matplot(grid, W, type = "l", lty = 1, lwd = 1.2,
        col = c("#5b21b6", "#7c3aed", "#8b5cf6", "#a78bfa", "#c4b5fd"),
        main = "Cinco caminatas escaladas -> trayectorias brownianas",
        xlab = "t", ylab = "W(t)")
abline(h = 0, col = "gray70", lty = 3)

# Marginal en t = 1: debe ser N(0, 1)
trayectorias <- replicate(2000, caminata())
finales <- trayectorias[n, ]
cat("media W(1):", sprintf("%.3f", mean(finales)),
    "| sd:", sprintf("%.3f", sd(finales)), "\\n")
# Cov(W(0.25), W(0.5)) sobre la MISMA trayectoria: teorica min(s,t) = 0.25
cat("cov(W(0.25), W(0.5)) empirica:",
    sprintf("%.3f", cov(trayectorias[501, ], trayectorias[1001, ])),
    "| teorica:", 0.25, "\\n")`}

## 3. Variación cuadrática: la firma del browniano

Toma una partición de $[0, t]$ cada vez más fina y suma los cuadrados de los
incrementos. En una función suave eso tiende a cero; en el browniano
converge a $t$:

$$\sum_{k} (W_{t_{k+1}} - W_{t_k})^2 \xrightarrow{\text{refinar}} t$$

La **variación cuadrática** acumulada del Wiener es $\langle W \rangle_t = t$:
crece linealmente y es determinística. Consecuencias que dominarán el módulo
siguiente:

- Las trayectorias tienen **variación total infinita** en todo intervalo —
  no se puede integrar "contra $dW$" al estilo Riemann-Stieltjes clásico.
- Las trayectorias son **no diferenciables en ningún punto**: por eso la
  notación $dW_t$ necesita un cálculo nuevo (Itô) en vez de reglas de Newton.
- En diferenciales: $(dW_t)^2 = dt$. Esta identidad formal es la que separa
  el lema de Itô de la regla de la cadena ordinaria, y es el punto del Taller
  2 que verificaremos numéricamente.

<Callout type="warning" title="Rugoso pero continuo">

El browniano es continuo casi seguramente y sin embargo no tiene derivada en
ningún lado. Ambas afirmaciones conviven porque la rugosidad es de orden
$\sqrt{h}$ en ventanas de tamaño $h$: suficiente para romper la tangente, no
suficiente para romper la continuidad. Los saltos del Poisson eran lo
contrario: discretos en instantes aislados.

</Callout>

## 4. Simetrías: el browniano se reescala a sí mismo

El proceso de Wiener tiene un grupo de invariancias notable, todas parte del
Taller 2:

- **Escalado**: para $c > 0$, $\tilde{W}_t = c^{-1/2} W_{ct}$ es de nuevo un
  proceso de Wiener. Acercar el tiempo y comprimir el espacio con la raíz
  deja la ley intacta: la autosimilaridad exacta del browniano.
- **Inversión temporal**: $B_t = t\, W_{1/t}$ (con $B_0 = 0$) también es
  Wiener. Intercambia infinito por origen.
- **Reflexión**: $-W_t$ es Wiener, y por la fuerte Markov, el máximo
  $M_t = \max_{s \leq t} W_s$ tiene la ley de $|W_t|$.

Del escalado sale el **puente browniano**: el proceso $B_t = W_t - t\, W_1$
en $[0, 1]$ es gaussiano, empieza y termina en cero, y tiene la ley del
browniano **condicionado a terminar en 0**. Es la base de muchos contrastes
de bondad de ajuste (Kolmogorov-Smirnov es la distancia de un puente al
origen).

<RCell
  id="09/wiener-escalado"
  title="Autosimilaridad y puente"
  code={`set.seed(28)
n <- 2000; grid <- seq(0, 1, length.out = n)
W <- c(0, cumsum(rnorm(n - 1))) / sqrt(n)

# Escalado: W(4t)/2 debe tener la misma ley que W(t)
# verificacion por replicas: sd en t = 0.5 debe ser sqrt(0.5) en ambos casos
rep_orig <- replicate(1000, sum(rnorm(500)) / sqrt(999))
rep_resc <- replicate(1000, sum(rnorm(2000)) / (2 * sqrt(999)))  # W(2)/2
cat("sd W(0.5):", sprintf("%.3f", sd(rep_orig)),
    "| sd W(2)/2:", sprintf("%.3f", sd(rep_resc)),
    "| teorica:", sprintf("%.3f", sqrt(0.5)), "\\n")

# Puente browniano: W(t) - t*W(1), termina en 0 siempre
puente <- W - grid * tail(W, 1)
plot(grid, puente, type = "l", col = "#5b21b6", lwd = 1.5,
     main = "Puente browniano: B(t) = W(t) - t·W(1)",
     xlab = "t", ylab = "B(t)")
abline(h = 0, col = "gray60", lty = 2)
cat("B(1) =", sprintf("%.2e", tail(puente, 1)), "\\n")`}
