<Callout type="tip" title="La interacción no es un sesgo, es un hallazgo">
Confusión: el agregado miente y hay que corregirlo. Interacción: los
estratos difieren *de verdad* y hay que describirlo. La modificación de
efecto dice que el efecto de $E$ sobre $D$ **cambia según el nivel de otro
factor**; no se corrige, se reporta por estrato.
</Callout>

## Los tres tipos de interacción (Woodward, Fig. 4.7)

- **Sinergismo**: mismo signo y magnitud amplificada; el efecto conjunto
  supera lo que cada factor haría solo.
- **Antagonismo**: el efecto cambia de signo entre estratos. El ejemplo
  canónico del <Term k="SHHS">SHHS</Term> (Ejemplo 4.13): el <Term k="RR">RR</Term> de tabaquismo para CHD es
  **2.40** en personas sin infarto previo pero **0.64** en quienes ya lo
  tuvieron (los infartados que sobrevivieron forman un grupo seleccionado
  resistente, o cambiaron de hábito).
- **Unilateralismo**: el efecto existe solo en presencia del segundo
  factor: RR distinto de 1 en un estrato, exactamente 1 en el otro.

## La escala importa

Woodward (Ch. 4.8.3): el test de interacción **depende de la escala**.
Puede haber interacción multiplicativa (los RR difieren) sin interacción
aditiva (las diferencias de riesgo son iguales), y viceversa. La
epidemiología de salud pública privilegia la aditiva (importa el exceso
absoluto de casos); la analítica clásica reporta la multiplicativa (los
RR u <Term k="OR">OR</Term> entre estratos).

## El test de homogeneidad de Breslow–Day

$$
\chi^2_{BD} = \sum_k \frac{\left(\ln \widehat{OR}_k - \ln \widehat{OR}_{MH}\right)^2}
{\mathrm{Var}(\ln \widehat{OR}_k)},
\qquad \text{gl} = K - 1
$$

Si los OR por estrato difieren (BD significativo), no procede resumirlos
con <Term k="MH">MH</Term>; hay que reportar el OR por estrato.

<RCell
  id="10/breslow-day"
  title="¿Un solo OR o uno por estrato? (Breslow–Day)"
  code={`# Homogeneidad de OR entre K estratos: Breslow-Day con correccion
# de Tarone (en SAS: TABLES ... / CMH + opcion BDT).
# Idea: bajo un OR comun psi (el de Mantel-Haenszel), cada celda 'a' tiene
# un valor esperado que se resuelve numericamente; chi^2 = suma (a-E)^2/V.
breslow_day <- function(arr) {
  K <- dim(arr)[3]
  num <- sum(apply(arr, 3, function(t) t[1,1]*t[2,2]/sum(t)))
  den <- sum(apply(arr, 3, function(t) t[1,2]*t[2,1]/sum(t)))
  psi <- num/den                                  # OR comun de MH
  X <- 0; sa <- 0; se <- 0; sv <- 0
  for (k in 1:K) {
    t <- arr[,,k]; m1 <- sum(t[1,]); n1 <- sum(t[,1]); N <- sum(t)
    lo <- max(0, m1 + n1 - N); hi <- min(m1, n1)
    f <- function(a) a*(N - m1 - n1 + a) - psi*(m1 - a)*(n1 - a)
    ea <- uniroot(f, c(lo, hi), tol = 1e-10)$root  # E[a] bajo OR comun
    v  <- 1/(1/ea + 1/(m1-ea) + 1/(n1-ea) + 1/(N-m1-n1+ea))
    X  <- X + (t[1,1] - ea)^2/v
    sa <- sa + t[1,1]; se <- se + ea; sv <- sv + v
  }
  tarone <- X - (sa - se)^2/sv                     # correccion de Tarone
  list(ors = apply(arr, 3, function(t) t[1,1]*t[2,2]/(t[1,2]*t[2,1])),
       or_mh = psi, BD = X, BD_Tarone = tarone,
       p = pchisq(tarone, K - 1, lower.tail = FALSE))
}

# Caso A: estratos homogeneos (mismo OR): BD ~ 1.35, p ~ 0.25
A <- array(c(40,60,20,180, 50,10,60,40), dim = c(2,2,2))
print(breslow_day(A))

# Caso B: estratos con OR distintos -> interaccion, no resumir:
# BD ~ 135, p ~ 0: homogeneidad rechazada con claridad
B <- array(c(40,60,20,180, 10,90,80,20), dim = c(2,2,2))
print(breslow_day(B))`}
/>

data A; input k $ e $ d $ n; datalines;
1 si si 40  1 si no 20  1 no si 60  1 no no 180
2 si si 50  2 si no 60  2 no si 10  2 no no 40 ;
data B; input k $ e $ d $ n; datalines;
1 si si 40  1 si no 20  1 no si 60  1 no no 180
2 si si 10  2 si no 80  2 no si 90  2 no no 20 ;

proc freq data=A order=data; weight n;
  tables k*e*d / cmh bdt;   /* BDT = correccion de Tarone */
run;
proc freq data=B order=data; weight n;
  tables k*e*d / cmh bdt;
run;
/* Caso B: Breslow-Day significativo -> los OR difieren de verdad:
   interaccion, reportar por estrato, no resumir con MH */`} />

<Callout type="note" title="La corrección de Tarone (1985)">
Cuando $\widehat{OR}_{MH}$ se estima de los mismos datos, el test de
Breslow–Day sin corregir es ligeramente liberal: usa los grados de
libertad K−1 como si el OR común fuera conocido, pero $\widehat{OR}_{MH}$
se estimó de los mismos datos. Tarone resta el término
$(\sum a_k - \sum E_k)^2/\sum V_k$, que nunca aumenta el estadístico
($X_{BDT} \le X_{BD}$) y lo vuelve ligeramente más conservador; en SAS
aparece como opción
<code>BDT</code>. La conclusión cualitativa rara vez cambia, pero es el
nombre que aparece en la literatura.
</Callout>

<Callout type="warning" title="La falacia del no-rechazo (tests agnósticos)">
Breslow–Day no significativo **no demuestra homogeneidad**: solo dice que
la evidencia no alcanzó para rechazarla. Coscrato, Izbicki y Stern (2018)
formalizan el problema: los tests clásicos controlan el error tipo I pero
no el tipo II, así que "no rechazo ≠ aceptación". Su propuesta de tests
agnósticos añade una tercera respuesta: "la muestra no decide". Con
pocos estratos o estratos pequeños, la respuesta honesta suele ser la
tercera.
</Callout>

<Callout type="tip" title="La regla de decisión del bloque">
1. Estratifica por el sospechoso.
2. Si los OR por estrato difieren entre sí (Breslow–Day significativo) →
   **interacción**: reporta cada estrato, no hay resumen honesto.
3. Si son homogéneos pero difieren del crudo → **confusión**: reporta
   $\widehat{OR}_{MH}$.
4. Si todo coincide → no había problema.
</Callout>
