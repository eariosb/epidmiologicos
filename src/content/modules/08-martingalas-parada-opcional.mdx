## 1. Juegos justos

Un proceso $\{M_n\}$ es una **martingala** respecto de $\{X_n\}$ (o de su
propia historia $\mathcal{F}_n$) si

$$E[M_{n+1} \mid \mathcal{F}_n] = M_n$$

con $E|M_n| < \infty$. La traducción es la del juego justo: **conocido el
pasado, el valor esperado de mañana es el valor de hoy**. El azar mueve la
trayectoria, pero no su promedio condicional.

La caminata aleatoria simétrica del módulo 1 es martingala: cada paso suma
$\pm 1$ con media cero, así que $E[S_{n+1} \mid \mathcal{F}_n] = S_n$. La
versión con deriva no lo es, pero sus correcciones sí — y ahí empieza la
magia de este tema: **casi todo proceso razonable se convierte en martingala
después de quitarle su tendencia**.

## 2. Tres familias que aparecen en el Taller 2

**La suma.** Si los incrementos tienen media $\mu$, entonces $S_n - n\mu$ es
martingala. Es la corrección universal de procesos aditivos: la misma idea
que quitará la deriva del browniano en el bloque III.

**El producto y el cociente.** Si $X_1, X_2, \dots$ son independientes con
$E[X_i] = 1$, el producto $M_n = X_1 X_2 \cdots X_n$ es martingala. Variante
clave: en una caminata asimétrica con $P(+1) = p \neq 1/2$, el proceso
$(q/p)^{S_n}$ es martingala porque $E[(q/p)^{X}] = p(q/p) + q(p/q) = 1$.

**La urna de Pólya.** Una urna empieza con $r$ bolas rojas y $b$ negras; en
cada paso se extrae una bola y se devuelve con otra del mismo color. Si
$M_n$ es la fracción de rojas, un cálculo directo muestra
$E[M_{n+1} \mid \mathcal{F}_n] = M_n$: la fracción es martingala, converge a
un límite aleatorio con ley Beta, y esa convergencia es exactamente lo que
verificaremos por simulación.

<Callout type="tip" title="Martingalas vs Markov">

Son propiedades ortogonales: hay martingalas que no son de Markov (la urna de
Pólya depende de toda la composición acumulada) y cadenas de Markov que no
son martingalas (cualquier cadena con deriva). Los procesos más útiles del
curso suelen ser las dos cosas a la vez.

</Callout>

## 3. El teorema de parada opcional

Un **tiempo de parada** $\tau$ es un instante aleatorio cuya decisión solo
usa información disponible: "para cuando el capital llegue a 0 o a $N$",
"para la primera vez que salga cara". Lo que no es tiempo de parada: "para
un paso antes de la racha ganadora" — requeriría ver el futuro.

El teorema de **parada opcional** (Doob) dice que si $\tau$ es tiempo de
parada y se cumple una condición de regularidad (martingala acotada, o
$\tau$ acotado, o $E[\tau] < \infty$ con diferencias acotadas), entonces:

$$E[M_\tau] = E[M_0]$$

La intuición del casino: ninguna estrategia legítima de "salir a tiempo"
convierte un juego justo en ganador. Lo que sí puede hacer la estrategia es
redistribuir la probabilidad entre ganar poco y perder mucho.

<Callout type="warning" title="La regularidad no es burocracia">

Sin la condición de regularidad el teorema falla en serio: en una caminata
simétrica, para cuando $S_n = 1$ por primera vez. Ese $\tau$ es finito casi
seguramente, pero $E[S_\tau] = 1 \neq 0 = S_0$. El tiempo de primera llegada
tiene esperanza infinita, y eso rompe las hipótesis. En el Trabajo 2 se pide
justamente identificar cuándo la parada opcional aplica y cuándo no.

</Callout>

## 4. La ruina del apostador, por martingalas

El problema clásico del Taller 2 se resuelve en dos líneas con Doob. El
apostador empieza con $i$, gana o pierde 1 por ronda con probabilidad $p$
($q = 1 - p$), y para al quebrar ($0$) o al llegar a $N$. Sea $\tau$ el
tiempo de parada.

**Caso simétrico** ($p = 1/2$): $S_n$ es martingala. Por Doob,
$i = E[S_\tau] = 0 \cdot P(\text{ruina}) + N \cdot P(\text{éxito})$, y la
probabilidad de llegar a $N$ antes de quebrar es $i/N$.

**Caso asimétrico**: se usa la martingala $(q/p)^{S_n}$:
$(q/p)^i = 1 \cdot P(\text{ruina}) + (q/p)^N \cdot P(\text{éxito})$, que
despeja la probabilidad de éxito:

$$P(\text{éxito}) = \frac{(q/p)^i - 1}{(q/p)^N - 1}$$

**Tiempo esperado**: en el caso simétrico, $S_n^2 - n$ también es martingala
(la corrección cuadrática), y Doob da $E[\tau] = i(N - i)$.

## 5. Extinción en Galton-Watson

Las martingalas también resuelven la pregunta del módulo 1: sea $Z_n$ el
tamaño de la generación $n$, con descendencia media $\mu$. Entonces
$W_n = Z_n / \mu^n$ es martingala ($E[W_{n+1} \mid \mathcal{F}_n] = W_n$ por
linealidad de la descendencia), y otra martingala útil es $s^{Z_n}$ donde
$s$ es la raíz en $(0,1)$ de $s = G(s)$, la función generadora de la
descendencia. Por Doob sobre la absorción en 0 se obtiene que la
probabilidad de extinción es $s$: la raíz más pequeña de $s = G(s)$, que es
1 si y solo si $\mu \leq 1$. El umbral de extinción del módulo 1 era este
resultado en versión simulada.

# ---- 1-2. Ruina del apostador ----
juego <- function(i, N, p) {
  s <- i; t <- 0
  while (s > 0 && s < N) { s <- s + sample(c(-1, 1), 1, prob = c(1 - p, p)); t <- t + 1 }
  c(exito = as.numeric(s == N), tiempo = t)
}
res <- t(replicate(3000, juego(40, 100, 0.5)))
cat("P(exito) sim:", sprintf("%.3f", mean(res[, 1])),
    "| i/N =", 40/100, "\\n")
cat("E[tau] sim:", sprintf("%.0f", mean(res[, 2])),
    "| i(N-i) =", 40 * 60, "\\n")

p <- 0.49; q <- 1 - p
res2 <- mean(replicate(3000, juego(40, 100, p))[1, ])
p_teo <- ((q/p)^40 - 1) / ((q/p)^100 - 1)
cat("p = 0.49 -> P(exito) sim:", sprintf("%.3f", res2),
    "| teorica:", sprintf("%.3f", p_teo), "\\n")

# ---- 3. Urna de Polya: la fraccion es martingala y converge ----
urna <- function(r, b, n) {
  rojas <- r; frac <- numeric(n)
  for (k in 1:n) {
    if (runif(1) < rojas / (r + b + k - 1)) rojas <- rojas + 1
    frac[k] <- rojas / (r + b + k)
  }
  frac
}
matplot(replicate(8, urna(5, 5, 500)), type = "l", lty = 1,
        col = "#8b5cf6", lwd = 1,
        main = "Urna de Polya: cada trayectoria fija su propio limite",
        xlab = "extracciones", ylab = "fraccion de rojas")
finales <- replicate(2000, tail(urna(5, 5, 500), 1))
cat("media de limites:", sprintf("%.3f", mean(finales)),
    "| Beta(5,5):", 0.5, "\\n")
cat("var de limites:", sprintf("%.4f", var(finales)),
    "| Beta(5,5):", sprintf("%.4f", 25/(100 * 11)), "\\n")

# ---- 4. Extincion Galton-Watson Poisson(mu) ----
extincion <- function(mu, gen_max = 40) {
  z <- 1
  for (g in 1:gen_max) { z <- rpois(1, z * mu); if (z == 0) return(1) }
  0
}
raiz_s <- function(mu) uniroot(function(s) exp(mu * (s - 1)) - s,
                               c(0, 0.999))$root
for (mu in c(0.9, 1.1)) {
  sim <- mean(replicate(3000, extincion(mu)))
  s_teo <- if (mu <= 1) 1 else raiz_s(mu)
  cat("mu =", mu, "| extincion sim:", sprintf("%.3f", sim),
      "| raiz s:", sprintf("%.3f", s_teo), "\\n")
}`}
