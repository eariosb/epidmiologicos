## 1. Las calificaciones como estados

Una calificadora resume el riesgo de un emisor en categorías: AAA, AA, A,
BBB, BB, B, CCC y D (default). Los emisores migran entre categorías en
tiempos irregulares: una rebaja llega cuando llega, no en fecha fija. Es
el terreno natural de la CTMC del módulo 7 — y el modelo estándar de la
industria (los estudios de migración de S&P y Moody's reportan justamente
matrices de transición anuales).

El estado D es **absorbente**: entrar es salir del modelo. Eso convierte la
matriz de transición $P(t) = e^{tQ}$ en la tabla de probabilidades de
migración a cualquier horizonte, y la columna de D en la **estructura
temporal de probabilidades de default** — el insumo del Trabajo 2 y de la
valoración de instrumentos riesgosos.

## 2. Estimar la generadora con tiempos de permanencia

El estimador de máxima verosimilitud de la CTMC es transparente: si el
emisor $i$ permaneció un tiempo total $T_i$ en cada estado y saltó $n_{ij}$
veces al estado $j$, entonces

$$\hat{q}_{ij} = \frac{n_{ij}}{T_i}$$

La tasa estimada es simplemente conteos por unidad de exposición — la
razón eventos/tiempo en riesgo de toda la vida, y la lógica de las tablas
anuales de las calificadoras (que estiman la matriz discreta $P(1)$ y a
veces "desescalan" a $Q$ tomando el logaritmo matricial).

Con datos agregados por año — la matriz $P$ anual publicada — la generadora
se recupera por la identidad $P(1) = e^{Q}$ vía el logaritmo de matriz,
disponible en `expm::logm`. Advertencia práctica que aparece en el Trabajo
2: el logaritmo puede tener componentes negativos fuera de la diagonal en
matrices mal condicionadas — ahí toca verificar validez y, si hace falta,
proyectar sobre generadoras válidas.

  code={`library(expm)
set.seed(40)

# Datos ficticios de una cartera: estados A, BBB, BB, D
estados <- c("A", "BBB", "BB", "D")
# tiempos totales en cada estado (años-emisor) y conteos de transicion
T_i <- c(A = 420, BBB = 380, BB = 150, D = Inf)
n <- matrix(c(0, 20, 5, 1,
              8, 0, 15, 2,
              1, 9, 0, 6,
              0, 0, 0, 0), 4, byrow = TRUE)

# Estimador MV: q_ij = n_ij / T_i
Q <- matrix(0, 4, 4)
for (i in 1:3) {
  for (j in 1:4) if (j != i) Q[i, j] <- n[i, j] / T_i[i]
  Q[i, i] <- -sum(Q[i, ])
}
rownames(Q) <- colnames(Q) <- estados
print(round(Q, 4))

# Matriz de migracion a 1, 3 y 5 años desde BBB
for (t in c(1, 3, 5)) {
  Pt <- expm(t * Q)
  cat("t =", t, "| P(BBB->D):", sprintf("%.4f", Pt["BBB", "D"]), "\\n")
}
# Estructura temporal de PD desde cada estado
anos <- seq(0.5, 10, by = 0.5)
pd_bb <- sapply(anos, function(t) expm(t * Q)["BB", "D"])
plot(anos, pd_bb, type = "l", col = "#5b21b6", lwd = 2,
     main = "Estructura temporal de PD desde BB",
     xlab = "horizonte (años)", ylab = "PD acumulada")`}

## 3. Trayectorias individuales por Gillespie

Para precios y escenarios hacen falta **caminos**, no solo marginales: la
calificación mes a mes de un emisor. El algoritmo de Gillespie del módulo 7
genera la trayectoria exacta: espera exponencial con la tasa total del
estado y salto proporcional a las tasas. Con eso se estima cualquier
funcional — tiempo de vida esperado de un crédito BB, probabilidad de
pasar por CCC antes del default, distribución del año del evento.

## 4. Lo que la CTMC no ve

El modelo Markov es el estándar industrial pero tiene dos puntos ciegos que
el Trabajo 2 discute: las migraciones reales muestran **momentum** (una
rebaja eleva la probabilidad de otra, contra la memoria nula), y los
defaults se **agrupan en el tiempo** por el ciclo económico común — la
correlación entre emisores que una cadena univariada no captura. Las
extensiones industriales (mezclas de cadenas, modelos de umbral tipo
CreditMetrics con factores comunes) abordan ambos; la CTMC queda como el
bloque de construcción de todo el edificio.

set.seed(55)
estados <- c("A", "BBB", "BB", "D")
T_i <- c(A = 420, BBB = 380, BB = 150)

# ---- 2. Estructura temporal de PD ----
for (t in c(1, 5, 10)) {
  Pt <- expm(t * Q)
  cat("t =", t, "| PD A:", sprintf("%.4f", Pt["A","D"]),
      "BBB:", sprintf("%.4f", Pt["BBB","D"]),
      "BB:", sprintf("%.4f", Pt["BB","D"]), "\\n")
}

# ---- 3. Tiempo esperado al default desde BB ----
# Sistema de tiempos absorbentes: -Q_sub * T = 1
Qsub <- Q[1:3, 1:3]
T_abs <- solve(-Qsub, rep(1, 3))
cat("E[tau_default] desde BB (exacto):", sprintf("%.1f", T_abs["BB"]), "\\n")
gillespie_default <- function(x0) {
  x <- x0; t <- 0
  while (x != 4) {
    qs <- -Q[x, x]
    t <- t + rexp(1, qs)
    dests <- setdiff(1:4, x)
    x <- dests[sample.int(3, 1, prob = Q[x, dests])]
  }
  t
}
t_sim <- mean(replicate(3000, gillespie_default(3)))
cat("E[tau_default] desde BB (sim):", sprintf("%.1f", t_sim), "\\n")

# ---- 4. PD a 5 años con IC Monte Carlo ----
pd5 <- function(x0) mean(replicate(5000, gillespie_default(x0) <= 5))
for (x in 1:3) {
  p <- pd5(x); ee <- 1.96 * sqrt(p * (1 - p) / 5000)
  cat("PD5", estados[x], ":", sprintf("%.4f ± %.4f", p, ee), "\\n")
}`}
