## 1. La anatomía de una EDE

Una ecuación diferencial estocástica escribe la dinámica de un proceso como
la suma de dos fuerzas:

$$dX_t = \underbrace{b(X_t, t)\, dt}_{\text{deriva}} + \underbrace{\sigma(X_t, t)\, dW_t}_{\text{difusión}}$$

La deriva es la tendencia determinística por unidad de tiempo; la difusión
inyecta ruido browniano amplificado por $\sigma$. Resolver la EDE es
encontrar el proceso $X_t$ (y su ley) que satisface la integral
$X_t = X_0 + \int b\, ds + \int \sigma\, dW_s$. El lema de Itô del módulo 10
es la herramienta para proponer y verificar candidatos.

Tres procesos dominan las aplicaciones del curso: **Ornstein-Uhlenbeck**
(reversión a la media), **browniano geométrico** (crecimiento porcentual) y
los modelos de tasa corta del Trabajo 3. Los dos primeros se resuelven en
forma cerrada; el resto se simula.

## 2. Ornstein-Uhlenbeck: el retorno a la media

La EDE $dX_t = -\alpha X_t\, dt + \sigma\, dW_t$ con $\alpha > 0$ describe
algo que la caminata y el browniano no hacen: **volverse hacia su nivel de
largo plazo**. La deriva es negativa cuando $X > 0$ y positiva cuando
$X < 0$, de magnitud proporcional a la desviación. Es el modelo canónico de
reversión: temperatura alrededor del promedio, spreads que se cierran, tasas
que regresan a un nivel estructural.

Aplicando Itô a $e^{\alpha t} X_t$ la EDE se integra de forma cerrada:

$$X_t = X_0 e^{-\alpha t} + \sigma \int_0^t e^{-\alpha(t-s)}\, dW_s$$

La integral es gaussiana (integrando determinístico, módulo 10), de modo que
$X_t$ es normal con

$$E[X_t] = X_0 e^{-\alpha t}, \qquad \mathrm{Var}(X_t) = \frac{\sigma^2}{2\alpha}\left(1 - e^{-2\alpha t}\right)$$

y en el largo plazo converge a la **estacionaria** $\mathrm{N}(0,
\sigma^2/2\alpha)$. La media olvida el arranque exponencialmente rápido; la
varianza se estabiliza en el equilibrio entre el ruido entrante y la
reversión que lo disipa.

# Media y varianza teóricas vs finales de la trayectoria
cat("X(8):", sprintf("%.3f", tail(ou, 1)),
    "| var estacionaria:", sprintf("%.3f", sigma^2/(2*alpha)), "\\n")
cat("sd cola de la trayectoria:", sprintf("%.3f", sd(ou[grid > 4])), "\\n")`}

## 3. Browniano geométrico: ruido porcentual

La EDE $dX_t = \mu X_t\, dt + \sigma X_t\, dW_t$ hace el ruido
**proporcional al nivel**: es el modelo de precios que crece o cae por
porcentajes, no por montos. El lema aplicado a $\log X_t$ la resuelve:

$$X_t = X_0 \exp\left(\left(\mu - \tfrac{\sigma^2}{2}\right) t + \sigma W_t\right)$$

La corrección $-\sigma^2/2$ en el exponente es Itô en acción: sin ella el
modelo sobreestimaría el crecimiento. Las distribuciones son lognormales,
los retornos logarítmicos gaussianos, y es la base de Black-Scholes y de los
modelos de default estructural del Trabajo 3 (Merton, Black-Cox).

## 4. Vasicek: OU con nivel de largo plazo

La tasa corta del Trabajo 3 usa la versión con nivel: $dr_t = \kappa(\theta - r_t) dt + \sigma dW_t$.
Misma mecánica del OU — reversión hacia $\theta$
con velocidad $\kappa$ — pero desplazada. La solución da $r_t$ gaussiana con
media $r_0 e^{-\kappa t} + \theta(1 - e^{-\kappa t})$ y varianza
$\sigma^2(1 - e^{-2\kappa t})/(2\kappa)$: transitoria gaussiana exacta, que
es lo que hace a Vasicek analíticamente tratable (y lo que el Trabajo 3
estimará sobre datos IBR/TIB colombianos).

<Callout type="warning" title="El precio de la gaussianidad">

Vasicek es tratable porque permite tasas negativas con probabilidad
positiva: la estacionaria es normal y la normal tiene colas a ambos lados.
El modelo CIR del Trabajo 3 cambia la difusión a $\sigma\sqrt{r_t} dW_t$ —
precisamente para que el ruido se apague cerca de cero. Esa comparación es
parte central del trabajo; por ahora basta entender por qué el ruido
proporcional a $\sqrt{r}$ cambia todo.

</Callout>

## 5. Euler-Maruyama: el simulador universal

Cuando no hay forma cerrada, la discretización de Euler-Maruyama es el
caballo de batalla: en pasos de tamaño $h$,

$$X_{k+1} = X_k + b(X_k)\, h + \sigma(X_k)\sqrt{h}\, Z_{k+1}, \qquad Z \sim \mathrm{N}(0,1)$$

Es la versión EDE del Euler de EDO: error débil $O(h)$ en distribución,
fuerte $O(\sqrt{h})$ en trayectoria. En el laboratorio se valida contra las
soluciones cerradas de OU y GBM — el mismo esquema que el Trabajo 3 usará
para CIR (que no tiene transición gaussiana exacta tan simple) y para la
validación Monte Carlo de precios de bonos.

n <- 3000

# ---- 1. OU: EM vs formulas cerradas ----
alpha <- 1.5; sigma <- 0.5; x0 <- 3; dt <- 5/2000
pasos <- 2000
em_ou <- function(t_fin) {
  x <- x0
  k <- round(t_fin / dt)
  for (i in 1:k) x <- x - alpha * x * dt + sigma * sqrt(dt) * rnorm(1)
  x
}
for (t in c(2, 5)) {
  xs <- replicate(1000, em_ou(t))
  mu_teo <- x0 * exp(-alpha * t)
  var_teo <- sigma^2 * (1 - exp(-2 * alpha * t)) / (2 * alpha)
  cat("t =", t, "| media:", sprintf("%.3f", mean(xs)), "~",
      sprintf("%.3f", mu_teo),
      "| var:", sprintf("%.3f", var(xs)), "~", sprintf("%.3f", var_teo), "\\n")
}

# ---- 2. GBM: media vs mediana ----
mu <- 0.08; sig <- 0.25; x0 <- 100
Z <- rnorm(2000)
X1 <- x0 * exp((mu - sig^2/2) + sig * Z)
cat("E[X1] sim:", sprintf("%.1f", mean(X1)),
    "| teorica:", sprintf("%.1f", x0 * exp(mu)),
    "| mediana:", sprintf("%.1f", median(X1)), "\\n")

# ---- 3. Vasicek exacto vs EM ----
kap <- 0.8; th <- 0.04; sv <- 0.02; r0 <- 0.06; dt <- 0.005
exacto <- function(t) {
  m <- r0 * exp(-kap * t) + th * (1 - exp(-kap * t))
  s <- sv * sqrt((1 - exp(-2 * kap * t)) / (2 * kap))
  rnorm(1, m, s)
}
em_v <- function(t) {
  r <- r0
  for (i in 1:round(t/dt)) r <- r + kap*(th - r)*dt + sv*sqrt(dt)*rnorm(1)
  r
}
ve <- replicate(1000, exacto(2)); vm <- replicate(1000, em_v(2))
cat("Vasicek t=2 | exacto m/sd:", sprintf("%.4f/%.4f", mean(ve), sd(ve)),
    "| EM:", sprintf("%.4f/%.4f", mean(vm), sd(vm)), "\\n")

# ---- 4. CIR y la condicion de Feller ----
cir_min <- function(kap, th, sv, r0, t_fin, dt = 0.005) {
  r <- r0; rmin <- r
  for (i in 1:round(t_fin / dt)) {
    r <- r + kap * (th - r) * dt + sv * sqrt(max(r, 0)) * sqrt(dt) * rnorm(1)
    if (r < rmin) rmin <- r
  }
  rmin
}
# Feller cumplida: 2*kappa*theta = 0.064 >= sigma^2 = 0.0004
f1 <- min(replicate(500, cir_min(0.8, 0.04, 0.02, 0.02, 2)))
cat("min r con Feller (sigma=0.02):", sprintf("%.4f", f1), "\\n")
# Feller violada: sigma^2 = 0.16 > 0.064
f2 <- min(replicate(500, cir_min(0.8, 0.04, 0.4, 0.02, 2)))
cat("min r sin Feller (sigma=0.4):", sprintf("%.4f", f2), "\\n")`}
